# 1. Summary

* **학습 일자**: 2026-06-30
* **핵심 주제**: 코틀린(Kotlin)의 클래스 활용 및 람다(Lambda) 함수
* **학습 범위**: 클래스 상속, 다형성, 추상 클래스, 인터페이스, 클래스 위임(Delegation), 고차 함수 및 람다식

# 3. Step-by-step Explanation

* **클래스 상속 및 타입 캐스팅**:
* `open` 키워드를 사용하여 상속 가능한 부모 클래스와 오버라이딩 가능한 메소드를 선언함.
* `is` 키워드로 객체의 타입을 검사하며, `as` 키워드를 통해 특정 타입으로 다운캐스팅(Downcasting)을 수행함.
* 객체 컬렉션 순회 시 `when` 표현식을 결합하여 다형성 기반의 분기 처리를 구현함.


* **추상 클래스 (Abstract Class) 및 오버로딩**:
* `abstract` 키워드가 선언된 클래스는 직접 인스턴스화할 수 없으며, 내부의 추상 메소드는 하위 클래스에서 반드시 구현해야 함.
* 동일한 메소드명을 가지되 매개변수의 수나 타입이 다른 메소드 오버로딩(Method Overloading)을 확인함.


* **인터페이스 (Interface) 및 위임 (Delegation)**:
* 구현부가 없는 추상 메소드(`fun fly()`)와 구현부가 포함된 기본 메소드(`fun land()`)를 정의함.
* `by` 키워드를 통해 클래스가 구현해야 할 인터페이스의 기능을 생성자 매개변수로 주입받은 객체에 위임(Delegation)함.


* **람다 함수 (Lambda Functions)**:
* 단일 매개변수를 가지는 람다식의 경우 `it` 키워드로 생략 및 접근이 가능함.
* 함수 자체를 반환값으로 가지거나(`fun multiplier`), 함수를 매개변수로 입력받아 내부 로직에 활용하는(`fun testFun`) 고차 함수의 구조를 확인함.
