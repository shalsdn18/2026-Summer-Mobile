# July09Application - 안드로이드 학습 프로젝트

## 📅 학습 날짜
2024년 7월 9일

## 📝 학습 내용 요약

오늘 학습한 주요 내용은 안드로이드의 다양한 UI 컴포넌트와 화면 전환 및 데이터 표시 방법입니다. 프로젝트 내의 각 모듈을 통해 다음과 같은 내용을 실습하였습니다.

### 1. 기본 액티비티 및 레이아웃 (`:app`)
- 안드로이드 앱의 기본 구조 이해
- XML 레이아웃을 이용한 UI 구성 (TextView, Button 등)
- ViewBinding을 활용한 뷰 참조 방식 학습

### 2. 프래그먼트 활용 (`:pregmentapp`)
- 하나의 액티비티 내에서 화면의 일부를 동적으로 교체하는 Fragment 이해
- `FirstFragment`, `SecondFragment`, `ThirdFragment`를 통한 화면 전환 실습

### 3. 드로어 레이아웃 (`:mydrawer`)
- `DrawerLayout`을 사용한 사이드 메뉴(Navigation Drawer) 구현
- `layout_gravity="start"` 속성을 이용한 슬라이딩 메뉴 구성

### 4. 리사이클러뷰 (`:recyclerview`)
- 대량의 데이터를 효율적으로 표시하기 위한 `RecyclerView` 사용법 학습
- `Adapter`와 `ViewHolder` 패턴을 이용한 리스트 아이템 바인딩 실습

### 5. 뷰페이저 (`:viewpager`)
- `ViewPager2`를 이용한 좌우 스와이프 화면 전환 구현
- 여러 개의 프래그먼트를 스와이프 인터페이스로 연결하는 방법 학습
