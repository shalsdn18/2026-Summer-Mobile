# July07Application 학습 일지

## 날짜: 2024년 7월 7일

## 학습 내용
- **Android Activity 및 Intent 활용**: 여러 개의 Activity(`MainActivity`, `SecondMainActivity`, `ThirdActivity`, `FourthActivity`)를 생성하고 `Intent`를 사용하여 화면 간 전환을 구현하였습니다.
- **View Binding 사용**: `build.gradle` 설정 및 `ActivityMainBinding` 등을 통해 레이아웃 요소에 안전하게 접근하는 방법을 익혔습니다.
- **레이아웃 디자인**: XML 레이아웃 파일을 통해 각 화면의 UI를 구성하고 버튼 클릭 이벤트를 처리하였습니다.
- **프로젝트 구조 이해**: Gradle 빌드 설정 및 라이브러리 의존성 관리를 확인하였습니다.
