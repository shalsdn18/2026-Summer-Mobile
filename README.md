\## 3. 항목별 상세 문법 및 에러 가이드 (Implementation Guide)



\### ① 변수 선언 및 타입 엄격성 (Variables \& Typing)

코틀린은 암시적 형변환을 허용하지 않는 매우 엄격한 정적 타입 시스템을 가집니다.

\* \*\*Int → Double 형변환 불가:\*\* `var data1: Double = 20`과 같이 정수 리터럴을 직접 대입하면 컴파일 에러가 발생하므로 반드시 소수점을 명시해야 합니다.

\* \*\*기초 타입 리터럴 규칙:\*\* `Float`는 숫자 뒤에 `F` 혹은 `f` 접미사가 필수적이며, 축약 표기법 중 숫자 직후 소수점만 찍는 형태(`20.`)는 허용되지 않습니다.

\* \*\*명시적 형변환:\*\* 큰 타입에서 작은 타입 혹은 반대의 경우에도 내부 탑재된 `.toInt()`, `.toDouble()` 등의 확장 메서드를 호출하여 변환을 명시해야 합니다.



```kotlin

var data1: Double = 20.0  // 정형화된 실수 대입

var data4: Float = 25.0F  // Float 지정 접미사



var data8: Int = 40

var data9: Double = 21.3

data8 = data9.toInt()     // 명시적 형변환을 통해 Double을 Int로 변환
